# OMI — Open Mesh Informator

Open Mesh Informator — программа для автоматической генерации и отправки сводок погоды в сеть LoRa (MeshCore и Meshtastic).

Скрипт получает данные о погоде, генерирует приветствие через локальную нейросеть Ollama с моделью Qwen2.5:3b, оптимизирует объем текста в байтах, делит длинные сообщения на части и отправляет их через MeshCore CLI.

Функционал
Оптимизация текста: заменяет некоторые кириллические буквы на аналогичные латинские символы, снижая размер сообщения в UTF-8 на 15–20%.

Разделение сообщений: режет длинный текст по знакам препинания, добавляет нумерацию частям (например, [1/2]) и делает паузу 10 секунд между отправками.

Очистка ответа: удаляет из текста нейросети иероглифы, переводы строк и кавычки.

Ограничение по времени: вызовы CLI ограничены таймаутом в 15 секунд.

Резервный режим: если сервис погоды недоступен, используется локальный шаблон.

Установка и запуск
Установите зависимости:
pip install requests meshcore-cli

Скачайте модель в Ollama:
ollama pull qwen2.5:3b

Укажите параметры в main_qwen2.5-3b.py:
SERIAL_PORT = "COM12"
MAX_BYTES = 110
OLLAMA_MODEL = "qwen2.5:3b"

Запустите скрипт:
python main_qwen2.5-3b.py
